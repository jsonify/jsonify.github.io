Features

  • Native macOS SwiftUI application
  • Sub-10ms click timing accuracy
  • Background operation without app focus
  • Global hotkey controls (ESC key)
  • Visual feedback with overlay indicators
  • Preset configuration system
  • Universal binary (Intel x64 + Apple Silicon)
  • Automatic updates via Sparkle framework

System Requirements

  • macOS: 15.0 or later
  • Architecture: Intel x64 + Apple Silicon
  • Permissions: Accessibility, Screen Recording
  • Memory: 4GB RAM minimum

Auto-Update System

ClickIt includes an automatic update system that checks for new versions daily. Updates are delivered securely through GitHub Releases.
